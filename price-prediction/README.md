# 🥬 농산물 시세 예측 — 배추 (가락시장)

최근 5년 월별 **기상 데이터 + 가락시장 배추 도매단가 + 재배면적**으로
배추 단가를 예측하는 프로그램이에요. 첫 품목으로 배추를 다루고,
구조는 다른 품목(무·양파 등)으로 확장 가능하게 만들었어요.

## 예측에 쓰는 인자

| 인자 | 설명 |
|---|---|
| **3개월 전 단가** ★ | 요청 인자 — 가격 추세 반영 |
| **작년 동월(동기간) 단가** ★ | 요청 인자 — 연 단위 계절 패턴 반영 |
| 1개월 전 단가 | 가격 관성 |
| 생육기(1~2개월 전) 기상 | 평균기온 편차 · 강수량 비율 · 폭염일수 |
| 출하 작형 재배면적 | 월별 출하 작형(봄/고랭지/가을배추)의 재배면적(ha) |
| 계절성 | 월 sin/cos 인코딩 |

모델: 그래디언트부스팅 회귀(scikit-learn). 최근 12개월 **전진(walk-forward) 검증**으로
성능을 확인하고(미래 정보 누출 없음), '작년 동월 단가 그대로' 나이브 예측과 비교해요.

## 빠른 시작

```bash
pip install -r requirements.txt
python3 generate_sample_data.py   # 샘플 5년치 데이터 생성 (API 키 없이 바로 실행)
python3 predict.py --horizon 6    # 학습 + 검증 + 6개월 예측
```

## 실측 데이터로 돌리기

API 키를 환경변수로 넣고 수집기를 실행하면 같은 파일명으로 저장돼요
(**키는 절대 커밋 금지** — CLAUDE.md 규칙과 동일).

```bash
export KAMIS_CERT_KEY=... KAMIS_CERT_ID=...   # www.kamis.or.kr 오픈API (도매가)
export KMA_API_KEY=...                        # apihub.kma.go.kr (기상)
export KOSIS_API_KEY=...                      # kosis.kr 공유서비스 (재배면적)
python3 fetch_data.py --start 2021-01 --end 2025-12
python3 predict.py
```

- 가격: KAMIS `periodProductList` — 배추(211) · 도매 · 상품 · 서울(가락시장 시세 반영)
- 기상: 기상청 API허브 지상관측 월값 (서울 108 지점 기준, 산지 지점으로 교체 가능)
- 면적: KOSIS 농작물생산조사 — 봄배추 / 고랭지배추 / 가을배추

## 데이터 파일 (data/)

| 파일 | 내용 |
|---|---|
| `price_garak.csv` | `date,price` — 월별 배추 도매가 (원/10kg망) |
| `weather.csv` | `date,tavg,rain,hot_days,cold_days` — 월별 기상 |
| `area.csv` | `year,spring_ha,highland_ha,autumn_ha` — 작형별 재배면적 |
| `forecast.csv` | 예측 결과 (predict.py 가 생성) |

⚠️ 현재 저장된 데이터는 실제 통계 패턴(여름·초가을 고랭지기 가격 급등,
2022·2024 폭염 해 등)을 본뜬 **합성 샘플**이에요. 실측으로 바꾸려면 위
`fetch_data.py`를 사용하세요. 예측 결과 해석도 실측 데이터 기준으로만 유효해요.

## 참고 (동작 방식)

- 다개월 예측은 **재귀 방식**: 예측한 단가를 다음 달의 lag 인자(1·3·12개월 전)로 재사용.
- 미래 기상은 평년값, 재배면적은 최근 연도 값으로 가정 — 전망치를 넣으면 정확도 개선 가능.
- 데이터가 늘어나면(월 단위 → 순/주 단위) 검증 구간과 모델 복잡도를 함께 키우는 걸 추천해요.
